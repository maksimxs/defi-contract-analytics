## defi-contract-analytics

Проект является аналитическим инструментом на основе восстановления состояния смарт-контрактов DeFi-проектов по истории их транзакций.

Скрипт собирает все вызовы контракта, далее по порядку воспроизводит их, повторяя логику смарт-контракта, 
и получает удобный доступ к разрозненным данным, благодаря чему составляется отчет, показывающий:
сколько уже получили участники DeFi-инструмента, 
сколько всего начислено, но не выведено, 
сколько контракт максимально обязуется выплатить в день и насколько этим пользуются участники. Затем баланс по симуляции сверяется с реальным балансом контракта в сети.

Анализируемые смарт-контракты являются высокорисковыми инструментами с фиксированной дневной доходностью. 
Главный вопрос, на который отвечает отчёт: на сколько дней хватит денег на контракте при текущих обязательствах.


## Схема работы 

Dune API -> SQLite -> Симуляция транзакций ->  Отчёт


## Пример отчёта
 
```
# 2023 10.24 02:05:10
Dune: 16123.9579 | Chain: 15534.565711441666 USDT | Difference: 589.3921885583331 USDT
 
Not invested money: 162.18385 USDT
Total Earned: 1811.6748611111116 USDT
Total lost profit: 28.686504629629617 USDT
 
Nature Daily: 465.829 USDT
MAX Daily: 511.6374999999995 USDT
 
Predict: 33.00005337031758 Days / Payback: 83.49013502690347 %
```

| Поле | Смысл |
|---|---|
| `Dune` / `Chain` / `Difference` | баланс контракта по симуляции, в сети и разница между ними |
| `Not invested money` | неиспользующиеся средства участников на контракте |
| `Total Earned` | сколько начислено участникам за всё время |
| `Total lost profit` | начисления, которые участники не успели забрать |
| `Nature Daily`, `MAX Daily` | ежедневные обязательства контракта |
| `Predict Days` | сколько дней контракт сможет исполнять свои обязательства |
| `Payback` | какой процент от вложения вернется тому, кто входит сейчас* |

\* При условии, что начисления будут забираться вовремя.
